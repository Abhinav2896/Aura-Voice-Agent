# Aura Receptionist Dashboard — SVG Assets

These SVGs are reconstructed vector assets inspired by the generated Aura receptionist dashboard template.
They are not extracted from the raster screenshot; the original generated image does not contain recoverable SVG source.

Use them in Next.js as:
- public/assets/*.svg
- <img src="/assets/aura-logo.svg" />
- CSS background-image: url('/assets/dashboard-bg.svg')

Recommended:
- Use lucide-react for production UI icons if you want interactive icon consistency.
- Use dashboard-bg.svg, sidebar-bg.svg, soft-grid.svg and decorative-wave.svg as decorative backgrounds.
- Use the individual icons for navigation/KPI cards.
